1. At a high level, how does a Power Automate 'Connector' interact with underlying services (like SharePoint or Outlook)?

B) It acts as an API wrapper that translates trigger events and user actions into authenticated REST HTTP requests (GET, POST, PATCH) with OAuth2 tokens.

2. An apprentice creates a flow that reads confidential payroll rows from Excel and uses an unapproved personal Dropbox connector to back it up. What enterprise security safeguard blocks this?

A) Data Loss Prevention (DLP) Policies, which segregate Business vs Non-Business connectors and block data exfiltration across boundaries.
B) Outlook Junk Email Filters.
C) The monitor's refresh rate.

3. When configuring an automated connector for a business approval flow, what represents security best practice for account authentication?

A) Hardcoding an individual director's personal login credentials directly into every action.
B) Using dedicated Service Principals or managed connection references following the Principle of Least Privilege.
C) Disabling Multi-Factor Authentication (MFA) across all organizational accounts.
